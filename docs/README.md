# Documentation

Project documentation for **Cloud-Based Smart Irrigation Recommendation using
Weather Intelligence** (BITE412L, Dr. Priya V).

## Purpose of this folder

`docs/` holds project-level documentation that is not tied to a specific
technical component — work allocation, planning records, meeting notes, review
material and, from Phase-II onward, design decisions and deployment runbooks.

Component-specific documentation lives with its component: architecture in
[`../architecture/`](../architecture/), datasets in [`../dataset/`](../dataset/),
literature in [`../literature_survey/`](../literature_survey/).
